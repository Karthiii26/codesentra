# CodeSentra — AI Code Detector

Detects whether a Python code snippet was written by a human or generated by an AI (ChatGPT, Gemini, Copilot, etc.).

Live at: **[codesentra-web.onrender.com](https://codesentra-web.onrender.com/)**

---

## How it works

The model extracts two types of features from the code:

- **Stylometric** — identifier entropy, comment density, cyclomatic complexity, naming consistency, line length, blank ratio, etc.
- **Perplexity** — how "predictable" the code is to CodeBERT. AI-generated code tends to score lower perplexity.

These 11 features are fed into a 3-layer PyTorch MLP trained on ~180 labelled Python files (human vs. Gemini-generated solutions to LeetCode-style problems).

## Running locally

```bash
pip install -r requirements.txt

# Start the API server
uvicorn api_server:app --host 127.0.0.1 --port 8000
```

Then open `src/web/index.html` in a browser, or point the frontend at `http://localhost:8000`.

## Features extracted

| Feature | What it captures |
|---------|-----------------|
| `identifier_entropy` | How varied the variable names are |
| `comment_density` | Ratio of comment lines to total lines |
| `avg_line_length` | Average characters per line |
| `cyclomatic_complexity` | Control flow complexity |
| `naming_style_uniformity` | Whether naming style is consistent |
| `whitespace_consistency` | Indentation regularity |
| `loc` / `sloc` | Total and non-blank line counts |
| `blank_ratio` | Fraction of blank lines |
| `mean_perplexity` | Average CodeBERT token predictability |
| `perplexity_variance` | Variance in token predictability |

---

## Limitations

- Trained on Gemini-generated code. May be less accurate on GPT-4 or Claude output.
- Short snippets (under ~10 lines) give unreliable results.
- This is a probabilistic score, not a definitive verdict.
